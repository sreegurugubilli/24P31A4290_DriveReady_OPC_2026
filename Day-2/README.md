# Day 2 – Restaurant Recommendation System 🍽️

## Project Description

The Restaurant Recommendation System is a Python-based application that recommends food items based on customer preferences and budget.

## Features

- Enter customer name.
- Select Veg or Non-Veg food preference.
- Choose preferred cuisine.
- Enter budget.
- Enter number of people.
- Get suitable food recommendations.
- Calculate estimated total cost.

## Technologies Used

- Python
- Google Colab

## How to Run

1. Open the Google Colab notebook.
2. Run the Python code.
3. Enter customer details.
4. View the recommended food items.
5. Check the estimated total cost.
